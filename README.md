8. Merge Sort
Question Description: Implement Merge Sort to arrange an array in ascending order. The algorithm divides the array into smaller subarrays, recursively sorts them, and merges the sorted subarrays into a single sorted array.

Test Cases:
- Test Case 1: Sort an unsorted array.
  - Input: 38 27 43 3 9 82 10
  - Expected Output: 3 9 10 27 38 43 82
- Test Case 2: Sort an array containing duplicate elements.
  - Input: 5 2 5 1 2
  - Expected Output: 1 2 2 5 5
Time Complexity:
- Best Case: \(O(n\log n)\)
- Average Case: \(O(n\log n)\)
- Worst Case: \(O(n\log n)\)
- Space Complexity: \(O(n)\)
